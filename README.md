## ✨ Features

* **Real-time Turn Switching:** Alternates smoothly between player `X` and player `O`.
* **Win/Draw Detection:** Instant win condition checks with clear game-over announcements.
* **Score Tracker / Reset Option:** Easy one-click game reset button to start a fresh round.
* **Responsive Design:** Optimized for both desktop and mobile screens.

---

## 🛠️ Built With

* **HTML5:** Clean, semantic structure for the game board.
* **CSS3:** Modern layout using Flexbox/Grid with smooth UI transitions.
* **JavaScript (ES6+):** Pure DOM manipulation and algorithmic win-checking logic without external libraries.

---

## 🎯 How to Play

1. The game is played on a **3x3 grid**.
2. Players take turns clicking on an empty cell to place their mark (**X** or **O**).
3. The first player to get **3 of their marks in a row** (horizontally, vertically, or diagonally) wins the game.
4. If all 9 cells are filled and no player has 3 in a row, the match ends in a **Draw**.
5. Click the **Restart / Play Again** button to begin a new match.
